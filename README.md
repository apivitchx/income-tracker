# Income Tracker

โปรแกรมบันทึกรายรับ-รายจ่ายด้วย Python

## ฟังก์ชันที่มี
- add_income(amount, note) — บันทึกรายรับ
- add_expense(amount, note) — บันทึกรายจ่าย
- summary(income, expense) — สรุปยอดคงเหลือ

## วิธีใช้งาน
add_income(5000, "เงินเดือน")
add_expense(1500, "ค่าอาหาร")
summary(5000, 1500)
